# Always Us 💗

Always Us is a couples-app prototype built with React Native and Expo.

## Current prototype
- Home screen
- Call screen (visual prototype only; real calls are not connected)
- This or That mini-game and daily questions
- Love notes
- Memories

## Run locally
Install Node.js, then run:

```bash
npm install
npx expo start
```

## Important notes
- Notes and memories are currently held in app state and are not synced to a database.
- The call buttons are placeholders; real-time audio/video calling has not been integrated.
- Supabase/database integration is a separate next step.
- The booking system is intentionally not included in this prototype change and must remain untouched.

This is a reconstructed starter snapshot based on the earlier project description, not a verified byte-for-byte copy of the original Expo Snack source.
